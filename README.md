# Applied Machine Learning

Coursework for Applied Machine Learning (CS 5785) at Cornell Tech, Fall 2026.

## Skills showcased

- **Supervised learning, from the ground up:** linear regression with ordinary least squares (Kaggle house prices), then logistic regression for classification (Kaggle Titanic), implemented in PyTorch.
- **Data preprocessing:** handling missing values, normalizing numeric features, one-hot encoding categorical features, and plotting feature distributions.
- **Text classification:** bag-of-words and 2-gram features, logistic regression with no, L1 and L2 regularization, and Bernoulli Naive Bayes, comparing generative and discriminative models by F1 score on a held-out dev set.
- **Dimensionality reduction:** eigenfaces (PCA by eigendecomposition) for face recognition, and measuring how much information a low-rank reconstruction loses.
- **Tree-based models:** decision trees and random forests, pre-pruning and cost-complexity pruning, and a k-NN baseline, used to rebuild an image from its pixel coordinates.
- **Tools:** Python, Jupyter, NumPy, pandas, matplotlib, scikit-learn, PyTorch.
